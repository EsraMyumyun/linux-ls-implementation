# linux-ls-implementation

**Реализация на Linux командата `ls` на езика C**

## 📌 Описание на проекта

`my_ls` е конзолно приложение, разработено на езика C (стандарт C99) за операционна система Linux. Проектът представлява собствена реализация на основните функционалности на системната команда `ls`.

Програмата извлича, обработва и визуализира информация за файлове и директории, като поддържа различни опции за филтриране, сортиране, форматиране и рекурсивно обхождане на файловата система.

Проектът е разработен като курсов проект по дисциплината **„Системно програмиране“**.

## ✨ Основни функционалности

- Извеждане на файлове и директории с цветово обозначаване.
- Показване на скрити файлове.
- Подробна информация за файловете – права за достъп, собственик, група, размер и дата на последна промяна.
- Форматиране на размерите в удобен за четене вид (KB, MB, GB и др.).
- Сортиране по име, размер и време на последна промяна.
- Обръщане на реда на сортиране.
- Рекурсивно обхождане на поддиректории.
- Комбиниране на няколко опции едновременно.
- Обработка на символни връзки.
- Адаптиране на изхода спрямо ширината на терминала.

## 🛠️ Използвани технологии

- **Език:** C (C99)
- **Операционна система:** Linux / Ubuntu
- **Компилатор:** GCC
- **Автоматизация на компилацията:** Makefile
- **Системни интерфейси:** `stat`, `lstat`, `opendir`, `readdir`, `readlink`, `ioctl`
- **Стандартни библиотеки:** stdio, stdlib, string, time, pwd, grp

## ⚙️ Поддържани опции

| Опция | Описание |
|---|---|
| `-a` | Показва всички файлове, включително скритите |
| `-l` | Подробен формат с информация за файловете |
| `-h` | Показва размерите в четим формат (K, M, G и др.) при използване с `-l` |
| `-R` | Рекурсивно обхождане на поддиректориите |
| `-S` | Сортиране по размер на файла |
| `-t` | Сортиране по време на последна промяна |
| `-r` | Обръща реда на сортиране |

Опциите могат да бъдат комбинирани, например `-lahR`.

## 🚀 Компилация и стартиране

### 1. Клониране на хранилището

```bash
git clone https://github.com/EsraMyumyun/linux-ls-implementation.git
```

### 2. Влизане в директорията

```bash
cd linux-ls-implementation
```

### 3. Компилиране

```bash
make
```

### 4. Стартиране

```bash
./my_ls
```

### 5. Почистване на генерираните файлове

```bash
make clean
```

## 💻 Примери за използване

**Стандартно извеждане:**

```bash
./my_ls
```

**Показване на скритите файлове:**

```bash
./my_ls -a
```

**Подробна информация за файловете:**

```bash
./my_ls -l
```

**Четим формат на размерите и показване на скритите файлове:**

```bash
./my_ls -lah
```

**Сортиране по време на промяна:**

```bash
./my_ls -lt
```

**Сортиране по размер:**

```bash
./my_ls -lS
```

**Рекурсивно обхождане:**

```bash
./my_ls -R
```

**Комбиниране на няколко опции:**

```bash
./my_ls -lahR
```

**Извеждане на информация за конкретна директория:**

```bash
./my_ls -laR /var/log
```

## 🧪 Тестване

В рамките на проекта са разгледани и тествани следните сценарии:

1. Основно извеждане на файлове и цветово обозначаване.
2. Подробен формат с опция `-l`.
3. Четим формат на размерите с опция `-lh`.
4. Сортиране по време и размер с `-t` и `-S`.
5. Рекурсивно обхождане с `-R`.
6. Комбинирана обработка с `-lahR`.

Тестовата директория `test_dir` съдържа поддиректория и файл за проверка на рекурсивното обхождане.
